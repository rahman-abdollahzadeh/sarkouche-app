# اپ اندروید سرِ کوچه

اپ رسمی که سایت **https://sarkouche.ir** را داخل WebView باز می‌کند.

| مورد | مقدار |
|------|--------|
| پکیج | `ir.sarkouche.app` |
| نسخه | ۱.۱.۰ |
| حداقل اندروید | ۷ (API 24) |

قابلیت‌ها:
- موقعیت مکانی (فروشگاه‌های نزدیک)
- انتخاب / گرفتن عکس (محصول و جواز)
- کشیدن برای رفرش
- دکمه برگشت
- درگاه پرداخت سپ و زرین‌پال داخل اپ
- Deep link به sarkouche.ir

## بدون اندروید استودیو — ساخت APK با GitHub (پیشنهادی)

### مرحله ۱ — ساخت ریپو
1. برو به [github.com](https://github.com) و وارد شو (اگر اکانت نداری بساز).
2. روی **New repository** بزن.
3. نام: `sarkouche-android`
4. Public باشد → **Create repository**.

### مرحله ۲ — آپلود فایل‌ها
دو روش:

**الف) از سایت GitHub (ساده‌تر):**
1. داخل ریپوی خالی روی **uploading an existing file** بزن.
2. همه فایل‌های داخل پوشه `sarkouche-android` را بکش و رها کن (کل پوشه، نه فقط یک فایل).
3. پایین صفحه **Commit changes**.

**ب) با GitHub Desktop** (اگر نصب داری) هم می‌توانی پوشه را اضافه کنی.

### مرحله ۳ — ساخت APK
1. در صفحه ریپو برو به تب **Actions**.
2. سمت چپ **Build APK** را انتخاب کن.
3. دکمه **Run workflow** → **Run workflow**.
4. ۲ تا ۵ دقیقه صبر کن تا سبز شود.
5. روی همان run کلیک کن.
6. پایین صفحه بخش **Artifacts** را ببین:
   - `sarkouche-debug-apk` → برای تست روی گوشی
7. دانلود کن، از حالت zip خارج کن، فایل `.apk` را نصب کن.

> اگر گوشی گفت «منابع ناشناس» را روشن کن: تنظیمات → امنیت → نصب از منابع ناشناس / نصب برنامه‌های ناشناس.

### مرحله ۴ — تست
- ورود خریدار و فروشگاه‌دار
- موقعیت مکانی
- افزودن محصول به سبد
- پرداخت تستی (بعد از اتصال درگاه)

## انتشار در بازار و مایکت

برای فروشگاه‌ها معمولاً **APK امضاشده (release)** لازم است.

جزئیات کامل در فایل **STORE-FA.md** آمده است.

خلاصه:
1. یک بار keystore بساز (رمز و فایل را گم نکن).
2. APK یا AAB امضاشده بساز.
3. در پنل بازار / مایکت توسعه‌دهنده شو.
4. آیکون ۵۱۲، اسکرین‌شات، توضیح و لینک حریم خصوصی را آپلود کن.

لینک‌های لازم:
- حریم خصوصی: https://sarkouche.ir/privacy.html
- پشتیبانی: https://sarkouche.ir/support.html
- سایت: https://sarkouche.ir
